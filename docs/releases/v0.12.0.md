## 2. 本版改了什么

### 2.1 高：贴图通道补齐，金属度 / 自发光 / 绒面从「只能给数值」到「可挂贴图」
- 表面类参数扩到 29 项，自发光贴图、绒面贴图、清漆层等接入同一套贴图挂接链路，V-Ray / Corona 两侧同步。
- 参数注册表由 62 项增至 65 项；新增项全部走 `Param.id` 注册表，`GET /api/schema` 与前端面板、`.ms` 生成器三处由同一份数据驱动，不存在手抄漂移。

### 2.2 高：Corona 侧「静默失效」属性显式点名
- Corona 有 11 个属性名（`brdf_fixDarkEdges`、`brdf_useRoughness`、`energyPreservation`、`refraction_glossiness`、`translucency`、`doubleSided`、`thinFilm_on` 等）在 CoronaPhysicalMtl 上写入不报错也不生效。
- 本版把它们从「静默丢弃」升级为「点名声明」：面板与导出日志明确告知用户哪些项在 Corona 下不起作用，避免拿着一张参数全对的表去猜为什么渲染不对。

### 2.3 中：降级文案与 `FALLBACK` 实现钉死同向，门禁 16 → 18 项
- 降级到 `PhysicalMaterial` 的文案曾两度与实现相反（先说「尽量映射」实际什么都不写，后说「不写任何参数」实际已重写）。
- 新增 `scripts/fallback_claim_check.py`：文案与 `tpl_common.FALLBACK` 中真实写入点数量必须同向，任一侧改动而另一侧不跟即门禁 FAIL。文案-实现一致性由此从人工约定变成硬门禁。

### 2.4 中：AI provider 不再把「配了 Key」当「可用」（C7 判据）
- 只有 Key 配好、但上游实际不可用时，旧行为仍会声明「AI 可用」。本版把判据改为「声明与实现同向」，前端不再展示一个点不动的 AI 入口。

### 2.5 中：批量导出与「我的预设」
- `POST /api/batch_export`：一次多图多套材质，参数共用当前面板、材质名沿用文件名、每套独占子目录，返回逐项 `ok` / `ms_path` / `dir` / `error`。
- `GET/POST/DELETE /api/presets/user`：面板调顺手可存为「我的预设」，一点套回整套面板；与内置预设同名会被拒（中英文都算）。
- 预设落盘在 `~/.3dsmax_material_forge/user_presets.json`，**不放 localStorage**：预设是用户资产，换浏览器、重装前端都不该丢；localStorage 只存面板会话状态。

### 2.6 中：自检注释括号误报修复
- 预检把脚本注释里的括号计入配对统计，导致合法脚本被判「括号不闭合」。已修，批量场景下不会再因此整批失败。

### 2.7 工程：真实世界尺寸 UV 取证探针 + 真机日志判读器固化
- 新增 RW UV 探针与判读器（`rw_probe` / `rw_verdict` 两项门禁），判读口径按 `docs/evidence-ledger.md` §4 落地：多段日志只看最后一段，避免历史段覆盖当次结论。
- 门禁项 18 → 19。

## 3. 真机证据（本轮唯一新增的真机结论）
`docs/evidence/rwprobe_max2024_20261123.log`，3ds Max 2024 中文版 + V-Ray 6.20.06 + Corona 12：

| 判定项 | 结果 |
|---|---|
| `RW_PROPS_HIT` | 4 |
| `RW_PROPS_WRITABLE` | 4 |
| `RW_SCALE_SUPPORTED` | 1 |
| `VERDICT` | PASS |

命中属性：`StandardUVGen.realWorldScale` / `realWorldHeight` / `realWorldWidth`、`CoronaTexmap.realWorldScale`（Corona coords 侧取不到，已在探针里记明）。

探针本身在真机上暴露并修好两处硬伤：计数器与函数撞名（`::mfRwHit` vs `fn mfRwHit`）、`timestamp()` 返回整数不能直接拼接。

**边界必须说清**：这一版拿到的是「真实世界尺寸 UV 可写、可回读」的取证结论，生成侧的 RW UV 功能尚未落地（提交 `1e4e290` 明确标注 P3 前置）。不要把它读成「已支持真实世界尺度输出」。

## 5. 证据边界（必须一起读）
- **单版本真机基线**：只有一台机器（Max 2024 中文 + V-Ray 6.20.06 + Corona 12）。`docs/version-matrix.md` 里 Max 2021–2026 / V-Ray 5–7 / Corona 9–13 的其余条目一律是 `supported` 或 `untested`，不是「已验证」。
- **0.12.0 的新功能没有真机导出落槽验证**：批量导出、我的预设、新增三通道贴图、Corona 静默点名，验收均为静态检查 + 生成侧校验 + 反例自测；本轮真机只跑了 RW UV 探针。
- **静态通过 ≠ 真机通过**：台账规则第 2 条写明，静态检查通过只算「机制在位」。
- **降级仍是降级**：落到 `PhysicalMaterial` 得到的是通用 PBR 近似材质（名字带 `_降级_` 前缀），没有折射透射、色散、涂膜、绒毛、SSS 分层与置换材质槽，与目标材质不等价。
