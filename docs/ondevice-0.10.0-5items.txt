    真机默认值：Corona dispersion = 40.0 + dispersionEnable = false
                VRayMtl refraction_dispersion = 50.0 + refraction_dispersion_on = false
    量程实测（probeF）：写 0 / 0.02 / 0.2 / 1 / 5 / 40 / 100 / 1000 全部原值回读，无钳制
    结论：两端是同一无量纲 0~100 标度，此前「V-Ray 0~1、Corona 0~100 需换算」的假设错误，取消换算。
    参数拆为两件：dispersion_on（开关）+ dispersion（0~100 强度）。
    开关关闭时一个色散属性都不下发，保留渲染器自己的默认值；
    此前 dispersion=5.0 无条件下发，等于把所有材质的色散从 40/50 改成 5。
